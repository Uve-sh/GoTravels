# GoTravels — Editorial Travel Platform

A boutique, photography-led travel website inspired by the editorial design language of [visittheusa.com](https://www.visittheusa.com/). Featuring curated heritage circuits, backwater wellness journeys, Himalayan expeditions, and bespoke travel concierge booking.

## 🌟 Highlights & Features
- **Editorial Typography & Hierarchy**: Classic serif titles (*Playfair Display*) paired with geometric sans-serif subheads (*Montserrat*) and clean UI copy (*Inter*).
- **Cinematic Hero Experience**: Full-bleed slider with location badges, slide counter (`01 / 04`), and responsive arrow controls.
- **Trip Finder**: Clean horizontal search bar for destination, duration, and travel style filtering.
- **Curated Experience Mosaic**: Asymmetrical 7-col and 5-col photo story grid for discovery.
- **Interactive Tour Packages**: Category tabs (Heritage, Wellness, Himalayas, Coast, International) with live filtering.
- **Architectural Trust Pillars**: Numbered operational guarantees (certified regional historians, transparent pricing, 24/7 on-ground concierge).
- **Concierge Booking Modal**: Interactive trip planning consultation dialog.

## 🚀 Live on GitHub Pages
This project is configured for instant hosting with **GitHub Pages**:
1. Go to repository **Settings** → **Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch `main` and folder `/ (root)`.
4. Click **Save**. Your site will be live at `https://<username>.github.io/<repo-name>/`.

## 💻 Local Development
To run locally on Windows:
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1 -Port 5500
```
Then visit `http://localhost:5500`.
